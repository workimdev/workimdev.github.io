TECHNICAL CASE STUDY

카카오 파스타 혈당 데이터 연동

외부 헬스케어 앱의 혈당 데이터를 병원 정보시스템(HIS)과 연결해, 의료진이 기존 진료기록에서 활용할 수 있도록 한 연동 프로젝트

ORGANIZATION
이지케어텍 · 분당서울대학교병원
PERIOD
2024
ROLE
.NET developer
STACK
C# · .NET · WPF · Oracle · PL/SQL · REST API · JSON · Apache Tomcat

보안과 기밀 유지를 위해 내부 시스템 식별 정보, API 세부 사양, 환자 데이터는 공개하지 않습니다. 외부 서비스의 환자 본인인증, 계정 매핑, 동의, 원천 데이터 수집은 본 HIS 연동의 담당 범위에 포함하지 않습니다.

배경과 제약

외부 헬스케어 앱의 혈당 데이터를 병원 진료기록 안에서 활용하려면, 중계 서버 기반 통신·인증과 REST API·JSON 처리, 기존 EMR 환자·수진 컨텍스트를 활용한 환자 연결이 필요했습니다. 이후 Ambulatory Glucose Profile(AGP) 리포트와 사전 적재된 혈당 가공 지표를 각각 기존 기록 작성 흐름과 진료서식에서 소비하도록 연결했습니다.

시스템 흐름

외부 데이터 연동 기반 흐름

외부 헬스케어 서비스
→
중계 서버 기반 통신·인증
→
REST API·JSON 수신/변환
→
EMR 환자·수진 컨텍스트를 활용한 환자 연결

AGP 리포트 소비 경로

외래 초진/경과기록
→
사용자·진료과·서식 조건 확인
→
AGP 리포트 조회
→
리포트 이미지 조회·수신
→
현재 진료기록 본문 삽입
→
기존 저장·서명 절차

혈당 가공 지표 소비 경로

환자 연결된 혈당 가공 데이터
→
Oracle DB 조회·PL/SQL 업무 처리
→
혈당 지표·그래프 데이터
→
진료서식 활용

상단은 외부 데이터를 HIS에 연결하는 기반 흐름이고, 아래 두 경로는 연결된 데이터를 소비하는 흐름입니다. AGP 리포트는 이미지로 현재 기록 본문에 반영하고, 혈당 가공 지표는 Oracle 기반 조회를 거쳐 진료서식에서 활용합니다.

구현 판단

HIS 연동 경계

외부 서비스와의 중계 서버 기반 통신·인증 흐름을 HIS 측 REST API·JSON 처리로 수용하고, 기존 EMR 환자·수진 컨텍스트를 활용해 환자를 연결했습니다.

조건 기반 기능 노출

공통 진료기록 헤더의 AGP 기능은 외래 여부, 기록 유형, 사용자, 진료과 조건을 확인한 뒤에만 노출되도록 구성했습니다.

공통 진료기록 인터페이스로의 확장

외부 혈당 데이터를 한 병원의 일회성 화면 기능으로 만들기보다, 기존 HIS의 공통 진료기록 인터페이스 안에 통합했습니다. AGP 조회·리포트 반영 기능은 공통 헤더에서 제공하고, 병원별 적용 대상은 사용자·진료과·기록 서식 조건으로 조정하도록 구성했습니다. 이를 통해 업무 정책은 조건 설정으로 조정하면서도 핵심 연동 흐름은 공통 구조로 유지해, 다른 병원 환경에도 포팅·확장할 수 있도록 고려했습니다.

두 소비 경로 분리

AGP 경로는 리포트 이미지를 조회해 현재 기록에 반영하고, 지표 경로는 Oracle·PL/SQL 기반 업무 처리를 거쳐 사전 적재 데이터를 진료서식에 매핑합니다.

기존 저장·서명 흐름과 오류 안내

AGP 리포트는 이미지 조회·본문 삽입까지만 담당하고, 이후에는 기존 기록 저장·서명 절차가 이어지도록 했습니다. 호출 실패 또는 리포트 미작성 상태는 확인 가능한 안내로 처리했습니다.

담당 범위

  • 중계 서버 기반 외부 연동 흐름에 맞춘 HIS 측 REST API·JSON 수신·변환 구현
  • 기존 EMR 환자·수진 컨텍스트를 이용한 환자 연결 및 공통 헤더의 조건 기반 AGP 기능 노출 구성
  • AGP 리포트 이미지 조회·현재 EMR 진료기록 본문 반영과 오류·미작성 안내 구현
  • Oracle DB 조회와 PL/SQL 기반 업무 처리를 통한 혈당 가공 지표·그래프 데이터의 진료서식 매핑
  • 리포트 반영 후 기존 기록 저장·서명 절차가 유지되도록 업무 흐름 연결

검증과 결과

외부 헬스케어 앱의 혈당 데이터를 환자별 진료기록 업무 흐름에서 활용할 수 있도록 했습니다. AGP 리포트 이미지는 현재 기록 본문에서 확인·반영하고, 혈당 가공 지표는 Oracle·PL/SQL 기반 조회를 거쳐 진료서식에서 활용하도록 연결했습니다.
