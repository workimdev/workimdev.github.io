# Younghwan Kim Portfolio

Personal portfolio site for [younghwankim.github.io](https://workimdev.github.io).

## Local preview

Open `index.html` in a browser, or run a static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Push this repository to `workimdev/workimdev.github.io` on the `main` branch, then enable **Settings → Pages → Deploy from a branch → main / root**.
